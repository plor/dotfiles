* dotfiles

Store configs and other files to be shared across systems.
BE CAREFUL NOT TO ADD SENSITIVE INFORMATION TO THIS DIRECTORY!
This uses GNU `stow` to manage the symlinks so the files
end up in the correct place. Currently a simple `stow .` will
work to do this, but if this changes writing a stow script
here would be of use.

tl;dr Run `stow .` from `.dotfiles/` to update symlinks
